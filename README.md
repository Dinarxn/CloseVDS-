# closeVDS — Frontend Foundation

This directory contains the Next.js App Router frontend foundation for **closeVDS** (AI Client Acquisition OS).

## Tech Stack
- **Framework**: Next.js (App Router, React 19)
- **Language**: TypeScript (Strict mode)
- **Styling**: Tailwind CSS (Monochrome Black & White design tokens)
- **Font**: Geist (`next/font/google`)

## Development & Build Commands

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Run ESLint validation
npm run lint

# Run TypeScript validation
npm run typecheck

# Build for production
npm run build
```
